## 一、安装与配置

### 1. 安装 Claude Code（VS Code 插件方式）

Claude Code 是 Anthropic 官方推出的 AI 编程助手。推荐通过 VS Code 插件安装，操作简单，无需命令行。

**安装步骤：**

1. 打开 Visual Studio Code。
2. 点击左侧活动栏的"扩展"图标（或按 `Ctrl+Shift+X`）。
3. 在搜索框中输入 `Claude Code`。
4. 找到由 Anthropic 发布的官方插件，点击 **安装**。
5. 安装完成后，VS Code 右下角会出现 Claude Code 的图标，表示插件已就绪。

> **提示：** 命令行方式安装较为复杂，不建议初学者使用。

### 2. 安装 CC Switch（API 切换工具）

CC Switch 是一款专为 Claude Code 等 AI 编程工具设计的 API 切换工具，支持在官方 API、国内镜像、第三方代理之间快速切换。

**安装步骤：**

1. 从可信源（如 GitHub 官方仓库）下载 CC Switch。
2. 根据操作系统提示完成安装（通常有图形界面或命令行两种形式）。
3. 安装后打开 CC Switch，熟悉其界面。

### 3. 配置国内 API（以 MiniMax 为例）

1. 注册 **MiniMax 开放平台** 账号，完成验证。
2. 进入控制台 → "API Keys" → 创建新密钥，保存好 Key。
3. 在 CC Switch 中点击"添加 API"，填入：
   - **API Endpoint：** `https://api.minimax.chat/v1/chat/completions`
   - **API Key：** 刚才获取的密钥
   - **模型名称：** 如 `abab6.5-chat`（以官方最新文档为准）
4. 保存并设为默认。
5. 在 Claude Code 插件设置中，将 API Base URL 指向 CC Switch 的本地代理地址（通常为 `http://127.0.0.1:8080`）。

### 4. 计算机硬件配置要求

| 级别 | 配置 |
|------|------|
| **最低配置** | 双核 CPU / 4GB 内存 / 10GB 硬盘 |
| **推荐配置** | 四核 CPU / 8GB 内存 / SSD 20GB 以上 |
| **操作系统** | Windows 10+（建议配合 WSL2）、macOS 12+、Linux |
| **网络** | 稳定的互联网连接（需能访问国内 API 域名） |

### 5. 隔离化安装建议（可选）

这不是强制要求，只是一个建议。对于机器配置较高（如内存 16GB 以上、有多余 CPU 核心）的用户，可以考虑在隔离环境中运行编程 Agent。

**为什么要隔离化安装？**

将编程 Agent 放在虚拟机或容器中运行，可以有效隔离其对主机的文件系统、系统配置的访问权限。即使 Agent 因 Bug 或误操作执行了删除、修改等危险命令，影响范围也被限制在隔离环境内，不会破坏宿主机的重要数据或系统文件。这对于保护个人文档、系统稳定性以及进行一些实验性操作非常有价值。

**推荐方案（二选一）：**

- **方案 A：Windows Hyper-V 虚拟机（仅限专业版/企业版）**
  - 启用 Hyper-V，创建 Ubuntu 虚拟机，在虚拟机内安装 Claude Code 和 CC Switch。每次实验前拍摄快照，出问题可秒级回滚。

- **方案 B：Docker 容器（适用于所有 Windows 版本）**
  - 拉取 `node:18` 镜像，在容器内安装工具。挂载项目目录时使用 `:ro`（只读），以非 root 用户运行，限制内存和 CPU。

> 如果您的机器配置一般，或者只是日常学习使用，直接在宿主机上运行也完全可以。隔离化安装是为追求更高安全性的用户提供的额外选择。

## 二、安全注意事项

### 1. 防止 Agent 误删重要文件的操作规范

- **最小权限原则：** 不要使用管理员（root/Administrator）身份运行 Claude Code。
- **写保护关键目录：** 对系统目录（如 `/etc`、`C:\Windows`）和个人文档文件夹设置只读权限，或禁止 Agent 访问。
- **人工二次确认：** 当 Agent 建议执行删除、覆盖、移动文件的命令时，务必先理解命令含义，确认无误后再执行。
- **版本控制与备份：**
  - 所有代码项目使用 Git 管理，并定期推送到远程仓库。
  - 重要数据遵循"3-2-1 备份策略"：3 份数据、2 种不同介质、1 份异地备份。

### 2. 其他安全细节

- **API Key 保护：** 使用环境变量或 `.env` 文件存储密钥，并确保 `.env` 已加入 `.gitignore`。绝不上传至公开仓库。
- **警惕危险命令：** 遇到 `rm -rf`、`dd`、`format`、`chmod 777` 等命令时，格外小心。
- **网络访问限制：** 若条件允许，在防火墙中限制 Agent 仅能访问必要的 API 域名（如 `api.minimax.chat`）。
- **审计日志：** 开启 CC Switch 的请求日志，定期检查是否有异常调用。
- **软件来源：** 仅从官方或可信源下载 CC Switch 及插件。

## 三、API 获取与管理

### 1. 国内 API 购买指南（以 MiniMax 为例）

1. **注册：** 访问 MiniMax 开放平台，手机或邮箱验证。
2. **获取 Key：** 控制台 → "API Keys" → 创建密钥。建议同时设置 IP 白名单（填入您的虚拟机或宿主机 IP）。
3. **充值：** 支持支付宝、微信支付。具体价格以官方定价页面为准，新用户通常有免费额度。
4. **配置：** 将 Key 和 Endpoint 填入 CC Switch。

> 其他国内模型（智谱 GLM-4、通义千问、DeepSeek 等）配置方式类似。

### 2. 国外聚合 API 购买指南（以 OpenRouter 为例）

OpenRouter 提供单一接口访问多种模型（Claude、GPT-4、Gemini 等），并且包含免费模型层，可零成本测试。

1. **注册：** 访问 OpenRouter，使用邮箱或 GitHub 登录。
2. **获取 Key：** 在 Dashboard 中创建 API Key，并设置每月消费上限。
3. **充值（可选）：** 如需使用付费模型，支持 PayPal、信用卡、加密货币。也可先使用免费模型。
4. **配置：** 在 CC Switch 中添加 Key，Base URL 设为 `https://openrouter.ai/api/v1`，调用时指定模型名称（如 `anthropic/claude-3-haiku`）。

### 3. 淘宝 / 闲鱼购买 API 的补充说明

**适用场景：** 临时测试、低预算、无法国际支付。

**操作建议：**

- 搜索关键词如 "MiniMax API"、"Claude API 代理"。
- 选择好评率高、开店时间长的卖家。
- 问清楚：Key 是独享还是共享、有效期、频率限制、是否提供售后。

> **风险提醒：**
> - 存在账号质量风险（盗刷、违规代理），可能导致 Key 突然失效或数据泄露。
> - 安全建议：仅小额购买（< ¥30）用于测试，不用于敏感项目；购买后立即绑定 IP 白名单（若支持）；定期更换 Key。
> - 教学建议：优先使用官方渠道或聚合平台，淘宝/闲鱼仅作为备选且需在教师指导下进行。
