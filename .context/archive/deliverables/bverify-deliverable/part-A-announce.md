## 一、背景：为什么我们要建树形会话执行体系

在 Proma 的演进过程中，我们很早就意识到一个现实问题：随着 Agent 能力的增强，单一会话处理复杂任务的方式正在触及天花板。当一项任务需要同时进行代码生成、调研分析、文档撰写与质量验证时，所有工作挤在同一个会话线程里，不仅上下文窗口不断膨胀，更会让不同性质的工作相互干扰，产生"方向漂移"与"职责混乱"。

**树形会话执行体系**的诞生，正是为了从根本上解决这一问题。它的核心理念是：将一项复杂任务分解为有向无环图（树状结构），每个子任务由独立的子会话（leaf）承接，子会话之间通过契约（contract）定义输入、输出与边界，由根会话（root）统筹协调。这种结构带来了三个显著优势：

1. **职责清晰**：每个 leaf 只做一件事，不会因为上下文污染而跑偏。
2. **并行能力**：独立的 leaf 可以并发执行，整体任务吞吐量大幅提升。
3. **可追溯性**：每个 leaf 输出结构化交付物，整棵树的执行过程都有迹可查。

这套体系的建立，标志着 Proma 从"单一 Agent 处理一切"的模式，迈向"结构化 Agent 协作"的新阶段。

## 二、v0.1 回顾：从实验到验收通过

v0.1 是树形会话执行体系的首个可用版本，承担着验证核心概念可行性的使命。在这一阶段，我们完成了基础框架的搭建：树状任务分解、子会话契约规范、交付物路径约定，以及根会话协调逻辑。

### 验收结论：通过

v0.1 经过完整的端到端测试，最终通过验收。验收过程中暴露并修复了三个关键问题：

**M1 — 契约边界不清晰**：早期版本中，in_scope 与 out_of_scope 的界定模糊，导致部分 leaf 越界处理了不属于自己的内容，造成交付物重叠。修复方案是在契约模板中强制要求明确列出 out_of_scope 条目，并在自审环节做边界合规检查。

**M2 — 交付物路径不一致**：多个 leaf 在写入文件时使用了不同的相对路径基准，导致根会话在汇总时无法稳定找到所有交付物。修复方案是统一规定所有交付物路径必须为绝对路径，并在 DoD（完成定义）中显式列出完整路径。

**M3 — 自检缺乏结构化输出**：初版的 done 消息为自由文本，根会话难以自动解析执行状态。修复方案是规定 done/blocked/plan 三个通道统一使用 YAML 格式，禁止散文汇报。

### S1 测试：通过

在标准验收测试套件 S1 中，树形执行体系在嵌套深度 CHAIN-DEPTH-3 的场景下完成了端到端走通，各层 leaf 契约执行正确，交付物路径全部有效，done 消息格式合规。S1 测试通过，体系稳定性得到初步确认。

## 三、v0.2 启动宣言：三大新能力，迈向更强的自治协作

v0.1 证明了树形会话执行体系的可行性，但它也让我们看清了下一步的方向：当 leaf 数量增多、任务链加长时，体系的韧性和自我修复能力变得至关重要。一旦某个 leaf 陷入沉默或偏航，整棵树的执行可能因为缺乏感知机制而悄然失败。

基于这一判断，**Proma v0.2 正式启动**。本版本的核心主题是：**在保持结构清晰的前提下，让体系具备更强的生命力与自我纠偏能力**。我们为此引入三大新能力：

**心跳通道（Heartbeat Channel）**：建立 leaf 向 root 定期报告存活状态的机制。leaf 在执行过程中不再只在完成时才发出信号，而是按约定节奏持续输出心跳，让根会话能够实时感知每个执行节点的状态。心跳通道从根本上消除了"静默失败"的盲区——当一个 leaf 异常沉默时，体系能够主动发现并介入，而不是等到汇总时才察觉。

**内部自审（Internal Self-Audit）**：每个 leaf 在完成主体工作后，必须对自身的执行过程进行结构化复盘：是否遵守了 in_scope 边界、交付物是否完整、自检 check-list 是否全部通过。内部自审将原本依赖外部验证的质量保障，内化为每个 leaf 的执行标准动作，让问题在最近的节点被发现和处理。

**三档纠偏（Three-Level Correction）**：当 leaf 执行出现偏差时，v0.2 提供三种梯度干预手段：自我修正（leaf 在 max_self_corrections 限额内自行调整）、请求援助（向 root 发出 blocked 消息寻求指引）、强制终止并回滚（root 主动中止失控的 leaf 并清理其状态）。三档纠偏机制为整个体系提供了有层次的容错保障，既避免了轻微偏差被过度干预，也防止了严重失控被放任自流。

v0.2 的这三大能力，共同构成了一个更加自治、更加可靠的协作框架。我们相信，随着这些能力的落地，Proma 的 Agent 协作将能够更优雅地应对复杂任务，为项目团队带来真正意义上的生产力跃升。

**Proma v0.2，正式启动。**
